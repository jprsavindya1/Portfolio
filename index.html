  • Gemini 1.5 Flash Model: Real-time high-speed API generations.
  • Dynamic Expiration: LocalStorage states auto-expire to keep memory fresh.
  • Location Mapping: Resolves Sri Lankan districts & popular travel hubs.

⚓ SLPA Port Entry Permit Specifications

A secure, enterprise-grade entry permit management system developed for the **Sri Lanka Ports Authority (SLPA)**. It automates security checks and streamlines access control operations for vehicles, employees, and visitors entering port facilities (such as the Galle Port).

📊 Executive Security Dashboard

Provides port administrators and gate personnel with real-time operations dashboards showing active permit counts, pending approvals, and compliance statuses. Active telemetry charts track incoming permit requests and approvals dynamically.

  • Real-time Telemetry: Live tracking of active entries & clearances.
  • User Compliance Gauges: Instant analysis of guest compliance percentages.
  • Interactive Activity Charts: Monthly analytics on visitor frequencies.

🎫 Multi-Type Permit Lifecycles

Supports full CRUD lifecycle operations for diverse permit types, allowing administrators to configure custom entry spans, security levels, and vehicle rate specifications.

  • Temporary Access: Single-day passes with instant automatic expiration.
  • Recurrent Passes: Multi-month access for port staff and engineers.
  • Vehicle Permits: Dedicated permits linked to transport container classes.

💳 Automatic Billing & PDF Invoices

Automates port tariff and entry fee calculations based on permit durations and vehicle weight categories. Generates professional PDF invoices in real-time with embedded barcodes and scan-to-verify QR codes.

  • Auto-Tariff Calculations: Dynamic cost computation engines.
  • DomPDF Engine: High-fidelity server-side PDF generation.
  • Scan-to-Verify QR Codes: Mobile-friendly invoice validation check.

🛡️ Gate Security & Blacklist Check

Strict validator blocks suspicious individuals and unauthorized vehicles instantly. Validates visitor NIC/Passport numbers and vehicle plates against a synchronized national blacklist database.

  • MySQL Advisory Locks: Prevents concurrent booking anomalies.
  • Incident Log Audits: Comprehensive system audit trails.
  • Gate Officer Panel: Instant alert banners with red color codes.
